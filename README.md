## 🚀 Як запустити проект

1. Встановіть WAMP Server
2. Клонуйте репозиторій у папку `C:\wamp64\www\`
3. Імпортуйте базу даних `lab5.sql` в phpMyAdmin
4. Відкрийте браузер за адресою: `http://localhost/lab1_backend/`
