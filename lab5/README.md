\## 🗄️ Структура бази даних



\### База даних: `lab5`



\### Таблиця `users` (15 полів)



| Поле | Тип | Опис |

|------|-----|------|

| id | INT | Первинний ключ, auto\_increment |

| login | VARCHAR(50) | Логін користувача (унікальний) |

| password | VARCHAR(255) | Хеш пароля |

| email | VARCHAR(100) | Email (унікальний) |

| full\_name | VARCHAR(100) | ПІБ користувача |

| phone | VARCHAR(20) | Телефон |

| address | TEXT | Адреса |

| city | VARCHAR(50) | Місто |

| postal\_code | VARCHAR(10) | Поштовий індекс |

| birth\_date | DATE | Дата народження |

| gender | ENUM | Стать (male/female/other) |

| reg\_date | TIMESTAMP | Дата реєстрації |

| last\_login | TIMESTAMP | Останній вхід |

| is\_active | TINYINT(1) | Активність |

| avatar | VARCHAR(255) | Шлях до аватара |



\### Таблиця `tov` (5 полів)



| Поле | Тип | Опис |

|------|-----|------|

| id | INT | Первинний ключ |

| name | VARCHAR(100) | Назва товару |

| cost | DECIMAL(10,2) | Вартість |

| quantity | INT | Кількість |

| date\_added | DATE | Дата додавання |

| description | TEXT | Опис |
