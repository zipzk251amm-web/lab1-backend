\## 🗄️ База даних



\### База даних: `lab6`



\### Таблиця `users`



| Поле | Тип | Опис |

|------|-----|------|

| id | INT(11) | Первинний ключ, auto\_increment |

| name | VARCHAR(100) | ПІБ користувача |

| email | VARCHAR(100) | Email (унікальний) |

| password | VARCHAR(255) | Хеш пароля |

| created\_at | TIMESTAMP | Дата реєстрації |



\### Таблиця `notes`



| Поле | Тип | Опис |

|------|-----|------|

| id | INT(11) | Первинний ключ |

| user\_id | INT(11) | Зовнішній ключ (зв'язок з users) |

| title | VARCHAR(200) | Заголовок замітки |

| content | TEXT | Текст замітки |

| created\_at | TIMESTAMP | Дата створення |

| updated\_at | TIMESTAMP | Дата оновлення |
