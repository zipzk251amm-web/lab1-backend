## 🗄️ База даних

### Таблиця `users`
| Поле | Тип | Опис |
|------|-----|------|
| id | INT | Первинний ключ |
| name | VARCHAR(100) | ПІБ користувача |
| email | VARCHAR(100) | Email |
| password | VARCHAR(255) | Хеш пароля |
| created_at | TIMESTAMP | Дата реєстрації |

### Таблиця `notes`
| Поле | Тип | Опис |
|------|-----|------|
| id | INT | Первинний ключ |
| user_id | INT | Зовнішній ключ |
| title | VARCHAR(200) | Заголовок |
| content | TEXT | Текст замітки |
| created_at | TIMESTAMP | Дата створення |
| updated_at | TIMESTAMP | Дата оновлення |
