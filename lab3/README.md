\## 🎯 Мета роботи



Навчитися працювати з файлами: створювати, читати, записувати і видаляти дані з файлів; працювати з каталогами; використовувати Cookie та Session; передавати файли через форми та приймати їх у PHP-скрипті.

\## 🍪 Завдання 1. Робота з Cookie



\*\*Опис:\*\* На сторінці створено 3 посилання: «Великий шрифт», «Середній шрифт», «Маленький шрифт». При натисканні встановлюється Cookie з вибраним розміром шрифту. Розмір зберігається при переході на інші сторінки.



\*\*Файл:\*\* `task1\_cookie\_font.php`



\*\*Реалізація:\*\*

\- Використано функцію `setcookie()` для збереження розміру на 30 днів

\- При завантаженні сторінки зчитується значення Cookie

\- CSS-класи змінюють розмір шрифту



\---



\## 🔐 Завдання 2. Робота з Session



\*\*Опис:\*\* Форма авторизації з полями «Логін» та «Пароль». При введенні `Admin` / `password` виводиться привітання. При оновленні сторінки стан авторизації зберігається. Реалізовано кнопку «Вийти».



\*\*Файл:\*\* `task2\_session\_login.php`



\*\*Реалізація:\*\*

\- Використано `session\_start()` для роботи з сесіями

\- Перевірка авторизації при кожному завантаженні сторінки

\- `session\_destroy()` при виході



\---



\## 📁 Завдання 3. Робота з файлами



\### 3.1 Гостьова книга

\*\*Опис:\*\* Форма з полями «Ім'я» та «Коментар». Дані зберігаються у файл `comments.txt`. Всі коментарі виводяться у вигляді таблиці.



\*\*Файл:\*\* `task3\_1\_guestbook.php`



\*\*Реалізація:\*\*

\- Формат зберігання: `Ім'я|Коментар|Час`

\- Використано `file\_put\_contents()` з `FILE\_APPEND`

\- Читання через `file()` та `explode()`



\### 3.2 Аналіз файлів

\*\*Опис:\*\* Дано два файли (`file1.txt`, `file2.txt`) зі словами. Створено 3 нових файли:

\- `only\_in\_first.txt` – слова тільки в першому файлі

\- `common\_in\_both.txt` – слова в обох файлах

\- `more\_than\_twice\_in\_each.txt` – слова, що зустрічаються >2 разів у кожному



Реалізовано форму для видалення створених файлів.



\*\*Файли:\*\* `task3\_2\_file\_processor.php`, `task3\_2\_delete\_file.php`



\### 3.3 Сортування слів

\*\*Опис:\*\* Файл `unsorted\_words.txt` зі словами. Слова впорядковано за алфавітом та збережено у `sorted\_words.txt`.



\*\*Файл:\*\* `task3\_3\_sort\_words.php`



\*\*Реалізація:\*\*

\- Читання файлу через `file\_get\_contents()`

\- Розділення рядка на масив слів за допомогою `preg\_split()`

\- Сортування через `sort()` та запис через `file\_put\_contents()`



\---



\## 🖼️ Завдання 4. Передача файлів через форми



\*\*Опис:\*\* Форма для завантаження зображень. Після відправлення зображення зберігаються в папку `uploads/` та відображаються в галереї.



\*\*Файл:\*\* `task4\_upload\_image.php`



\*\*Реалізація:\*\*

\- Атрибут форми: `enctype="multipart/form-data"`

\- Перевірка через `getimagesize()` для підтвердження, що файл є зображенням

\- `move\_uploaded\_file()` для збереження

\- Додавання часової мітки до назви файлу для уникнення дублікатів

\- Виведення галереї через `glob()`



\---



\## 📂 Завдання 5. Робота з каталогами



\*\*Опис:\*\* Форма з полями «Логін» та «Пароль». Створюється папка з іменем логіна (якщо не існує). Всередині створюються підпапки `video`, `music`, `photo` та приклади файлів. Окрема сторінка `delete.php` видаляє папку з усім вмістом.



\*\*Файли:\*\* `task5\_folder\_manager.php`, `delete.php`



\*\*Реалізація:\*\*

\- Фільтрація імені логіна через `preg\_replace()` для безпеки

\- `mkdir()` з параметром `recursive = true`

\- Рекурсивна функція `deleteFolder()` для видалення папки з усім вмістом
