\## ✅ Висновок



У ході виконання лабораторної роботи №2 я:



1\. Навчився працювати з \*\*рядками\*\* (заміна символів, сортування міст, виділення частин шляху, робота з датами, генерація паролів)

2\. Опанував роботу з \*\*масивами\*\* (пошук дублікатів, генерація випадкових імен, створення та обробка масивів, сортування асоціативних масивів)

3\. Створив \*\*багатомовну форму реєстрації\*\* з можливістю завантаження фото та збереженням даних у сесію

4\. Реалізував роботу з \*\*Cookie\*\* (збереження вибраної мови)

5\. Написав власні \*\*функції\*\* для математичних обчислень та підключив їх через `include`



Всі завдання виконано в повному обсязі, код працює коректно.
